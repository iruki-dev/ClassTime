개인정보처리방침

ClassTime (안드로이드, 패키지 dev.iruki.classtime) · 시행일 2026년 11월 26일

ClassTime은 개발자가 운영하는 서버가 없습니다. 개발자는 사용자의 녹음, 받아 적은 글, 요약, 계정 정보를 받거나 보관하지 않습니다. 아래는 앱이 기기 안에서 다루는 정보와, 사용자가 직접 켠 기능에 한해 외부 서비스로 보내는 정보입니다.

1. 기기에 저장하는 정보

  • 시간표: 과목명, 교수, 강의실, 수업 시간.
  • 녹음: 마이크로 녹음한 강의 음성. 기기의 Music/ClassTime 폴더에 저장됩니다.
  • 받아 적은 글과 요약(실험적 기능): 기기의 Documents/ClassTime 폴더와 앱 데이터베이스에 저장됩니다.
  • API 키(실험적 기능): 사용자가 입력한 Groq·Anthropic 키는 기기에 암호화해 저장하며 어디에도 보내지 않습니다(해당 서비스에 요청할 때 인증용으로만 씁니다).

이 정보는 앱을 삭제하거나 앱에서 지우면 사라집니다. 녹음·글 파일은 사용자의 기기 폴더에 있으므로 파일 앱에서 직접 지울 수도 있습니다.

2. 외부로 보내는 정보 (사용자가 켰을 때만)

기능보내는 것받는 곳
텍스트 변환변환할 녹음의 음성Groq, Inc. — 사용자의 Groq 키로 요청 (Groq 개인정보처리방침)

이 기능들은 기본으로 꺼져 있고, 처음 켤 때 무엇이 어디로 가는지 앱 안에서 안내하고 동의를 받습니다. 끄거나 키를 지우면 더 이상 보내지 않습니다.

3. Google 사용자 데이터

Google Drive 동기화는 drive.file 권한만 요청합니다. 이 권한으로 ClassTime은 이 앱이 만든 파일만 보고 고칠 수 있으며, 사용자 Drive의 다른 파일에는 접근할 수 없습니다.

  • 사용하는 데이터: Google 계정 이메일(설정 화면에 연결된 계정을 표시하는 데에만 사용), 이 앱이 만든 ClassTime 폴더와 그 안의 텍스트 파일.
  • 사용 목적: 기기의 받아 적은 글·요약을 사용자의 Drive에 올리고, 바뀌면 고치고, 앱에서 지우면 Drive 휴지통으로 옮기는 동기화에만 씁니다.
  • 저장과 공유: 접근 토큰은 기기에 저장하지 않고 필요할 때마다 Google Play 서비스에서 받습니다. Google 사용자 데이터를 개발자나 제3자에게 보내거나 팔지 않으며, 광고에 쓰지 않습니다.
  • 연결 해제: 앱 설정에서 ‘연결 끊기’를 누르면 권한을 해제합니다. Drive에 올린 파일은 그대로 남으며 사용자가 직접 지울 수 있습니다. Google 계정 › 서드 파티 연결에서도 해제할 수 있습니다.

ClassTime이 Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 수집하지 않는 것

광고, 분석(애널리틱스), 오류 수집 도구를 쓰지 않습니다. 위치, 연락처, 기기 식별자를 수집하지 않습니다.

5. 권한

  • 마이크: 강의 녹음.
  • 알림, 정확한 알람, 부팅 후 실행, 배터리 최적화 예외: 수업 시간에 맞춰 녹음을 시작·종료하고 상태를 알리기 위해.
  • 다른 앱 위에 표시: 화면이 꺼져 있을 때 시작된 자동 녹음에 소리가 담기도록(Android의 백그라운드 마이크 제한 예외). 화면에 무언가를 띄우는 데는 쓰지 않습니다.
  • 오디오 파일 읽기: 재설치 전의 녹음이나 PC에서 넣은 녹음을 목록에 보여 주기 위해.
  • 인터넷: 사용자가 켠 실험적 기능(변환·요약·Drive)에만.

6. 아동

ClassTime은 만 14세 미만 아동을 대상으로 하지 않습니다.
