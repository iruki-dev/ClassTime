ClassTime

시간표를 한 번 등록해 두면 수업 시간에 맞춰 강의를 자동으로 녹음하고, 과목별 폴더에 정리해 주는 안드로이드 앱입니다.

할 수 있는 일

  • 시간표대로 녹음을 시작하고 끝내요. 파일은 과목_날짜_시각.m4a로 과목별 폴더에 저장돼요.
  • 실험적 기능: 사용자가 넣은 Groq 키로 녹음을 글로 받아 적고, Anthropic(Claude) 키로 강의를 요약해요. 요약의 각 줄은 원문의 그 자리로 이어져요.
  • 실험적 기능: 받아 적은 글과 요약을 사용자의 Google Drive에 맞춰 둬요. 녹음 파일은 올리지 않아요.

개인정보

ClassTime에는 개발자가 운영하는 서버가 없고, 녹음과 글은 기기에 저장됩니다. 사용자가 켠 기능에 한해서만 Groq, Anthropic, Google Drive로 데이터가 전송됩니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
